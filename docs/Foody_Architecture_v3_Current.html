Foody — Architecture

Foody · Version 3.0 · ตรวจตามซอร์ส Android ณ 13 พ.ย. 2569 · ยังไม่ได้ยืนยัน Build/AVD

Architecture ปัจจุบัน (มีโค้ด)

Android Application · Kotlin + Jetpack Compose + Material 3
MainActivity · UI ตาม Role · Screens: Staff / Kitchen / Owner / Login / Settings
↓
FoodyStore : AndroidViewModel
UI State · Route · Demo Login · Business Actions · Coroutines
Assets
food-1.txt … food-8.txt · รูปอาหาร Base64
↓
Room / SQLite ภายใน Android เครื่องนั้น
foody_state(id, json) · SavedStateDao · JSON: tables, foods, orders, sales, notifications
ไม่มี REST/Retrofit, FastAPI, Server Database, Repository แยกชั้น หรือ Sync ข้าม Emulator ในซอร์สปัจจุบัน

Architecture เป้าหมาย (ยังไม่ได้ทำ)

Android Layer · Planned
Compose UI → ViewModel → Repository → Retrofit/OkHttp + Room Cache; Loading/Error/Offline; Notification Receiver
Server Layer · Planned
FastAPI → Auth/Role Validation → Session/Orders/Payments → SQL Database; Transactions / Idempotency / Audit Trail
⟷ HTTPS REST (ยังไม่เชื่อม)

เอกสาร v2 เคยแสดงชั้น Backend, JWT, WorkManager และ Notification เสมือนเป็น Architecture ปัจจุบัน จึงเปลี่ยนมาระบุเป็นเป้าหมายที่ยังไม่ implement
