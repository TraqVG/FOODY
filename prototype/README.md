# Foody Interactive UI v4

เปิด index.html ด้วย Google Chrome บนเครื่อง Windows

ไฟล์ที่ต้องเก็บไว้ด้วยกัน:
- index.html — หน้า UI และการโต้ตอบ
- styles.css — CSS
- assets/food-1.js ถึง assets/food-8.js — รูปอาหารแบบ Offline

บัญชีทดลอง (ไม่มีหน้าสมัคร):
- Staff: staff@foody.shop
- Kitchen: kitchen@foody.shop
- Owner: owner@foody.shop
- รหัสผ่านทุกบัญชี: foody123

Flow ทดลอง:
1. Staff เปิดโต๊ะ เลือกอาหาร แล้วส่งเข้าครัว
2. ออกจากระบบ เข้า Kitchen และกด เสร็จแล้ว
3. กลับไป Staff เพื่อเสิร์ฟและเช็กบิล
4. เข้า Owner เพื่อดูรายงานและจัดการเมนู

หมายเหตุ: HTML Prototype ไม่ใช่ Android APK ยังไม่เชื่อม FastAPI, Room หรือฐานข้อมูลกลาง
